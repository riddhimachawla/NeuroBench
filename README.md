# NeuroBench

NeuroBench is an EEG experimentation platform designed to simplify EEG data analysis, preprocessing, machine learning, and cross-subject generalization evaluation.

## Features

- EEG dataset loading
- Signal visualization
- EEG preprocessing
- Feature extraction
- Classical ML models
- Cross-subject evaluation
- Experiment tracking

## Tech Stack

- Python
- MNE
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
